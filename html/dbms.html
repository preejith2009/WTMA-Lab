DBMS Skill Test Preparation Notes

DDL • DML • Aggregate Functions • Subqueries

Before starting the quiz:

Read all four topics below and study the example queries carefully. The quiz questions are based on these concepts and SQL query patterns.

1. DDL – Data Definition Language

DDL is used to define and modify the structure of database objects such as tables and columns.

Important DDL Commands

Command Purpose
CREATE Creates a new database object such as a table.
ALTER Changes the structure of an existing table.
DROP Removes a database object or column.
TRUNCATE Removes all rows from a table while keeping the table structure.

ALTER TABLE – Rename a Column

To rename a column: 

ALTER TABLE STUDENT
RENAME COLUMN CGPA TO Grade_Point;

Here, the column CGPA is renamed to Grade_Point.

ALTER TABLE – Modify Column Size

To increase the size of the City column: 

ALTER TABLE STUDENT
MODIFY City VARCHAR(50);
Remember: MODIFY is used to change the definition of an existing column, such as its datatype or size.

ALTER TABLE – Remove a Column

ALTER TABLE STUDENT
DROP COLUMN Email;

This permanently removes the Email column from the table.

Exam Tip: Do not confuse DROP COLUMN with DELETE. DROP COLUMN changes the table structure, while DELETE removes rows.

2. DML – Data Manipulation Language

DML is used to manipulate the data stored inside tables.

Important DML Commands

Command Purpose
INSERT Adds new rows to a table.
UPDATE Modifies existing data.
DELETE Removes rows from a table.

UPDATE Example

Update Rahul's city to Mumbai: 

UPDATE STUDENT
SET City = 'Mumbai'
WHERE Student_Name = 'Rahul';
Very Important: Always check the WHERE condition in an UPDATE query. Without WHERE, all rows may be updated.

DELETE Example

DELETE FROM STUDENT
WHERE Student_Name = 'Rahul';

INSERT Example

INSERT INTO STUDENT
(Student_ID, Student_Name, Department, City)
VALUES
(101, 'Rahul', 'CSE', 'Chennai');

SELECT – Retrieving Data

The SELECT statement is used to retrieve data from a table. 

SELECT Student_Name, Department
FROM STUDENT;

This displays only the Student_Name and Department columns.

WHERE Condition

Display students whose CGPA is greater than 8: 

SELECT *
FROM STUDENT
WHERE CGPA > 8;

Display courses having more than 3 credits: 

SELECT *
FROM COURSE
WHERE Credits > 3;

3. Aggregate Functions

Aggregate functions perform calculations on a group of rows and return a single result.

Function Purpose Example
COUNT() Counts rows or values COUNT(*)
SUM() Calculates total SUM(Marks)
AVG() Calculates average AVG(Marks)
MIN() Finds minimum value MIN(Marks)
MAX() Finds maximum value MAX(Marks)

COUNT()

Count the total number of students: 

SELECT COUNT(*) AS Total_Students
FROM STUDENT;

Count students in the CSE department: 

SELECT COUNT(*) AS CSE_Students
FROM STUDENT
WHERE Department = 'CSE';

MIN()

Find the lowest marks obtained: 

SELECT MIN(Marks) AS Lowest_Marks
FROM ENROLLMENT;

MAX()

Find the highest marks obtained: 

SELECT MAX(Marks) AS Highest_Marks
FROM ENROLLMENT;

AVG()

Find the average marks: 

SELECT AVG(Marks) AS Average_Marks
FROM ENROLLMENT;

SUM()

Find the total marks: 

SELECT SUM(Marks) AS Total_Marks
FROM ENROLLMENT;
Remember:

COUNT = Number of records
SUM = Total
AVG = Average
MIN = Lowest value
MAX = Highest value

4. Subquery – Inner Query

A subquery is a query written inside another SQL query. The inner query is executed as part of the outer query.

A subquery is usually written inside parentheses: 

SELECT ...
FROM ...
WHERE column = (
    SELECT ...
);

Example 1 – Student with Lowest CGPA

SELECT *
FROM STUDENT
WHERE CGPA = (
    SELECT MIN(CGPA)
    FROM STUDENT
);

The inner query finds the minimum CGPA. The outer query then displays the student whose CGPA matches that value.

Example 2 – Using IN with a Subquery

Display course names associated with Student_ID 101: 

SELECT Course_Name
FROM COURSE
WHERE Course_ID IN (
    SELECT Course_ID
    FROM ENROLLMENT
    WHERE Student_ID = 101
);

The inner query obtains the relevant Course_ID values. The outer query uses those IDs to retrieve Course_Name.

Example 3 – Nested Subquery

Display students enrolled in Java Programming: 

SELECT *
FROM STUDENT
WHERE Student_ID IN (
    SELECT Student_ID
    FROM ENROLLMENT
    WHERE Course_ID = (
        SELECT Course_ID
        FROM COURSE
        WHERE Course_Name = 'Java Programming'
    )
);
Understand the flow:

1. Find the Course_ID for Java Programming.
2. Find Student_ID values enrolled in that Course_ID.
3. Display the corresponding students.

Example 4 – NOT IN

Display students who are not enrolled in any course: 

SELECT *
FROM STUDENT
WHERE Student_ID NOT IN (
    SELECT Student_ID
    FROM ENROLLMENT
);
