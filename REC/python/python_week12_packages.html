Week 10 - Python I/O Operations and Collection Packages

Python provides powerful features for handling input and output operations. It also offers collection packages that help programmers store and manipulate data efficiently.

I/O Operations allow programs to interact with files and users, while collection packages provide advanced data structures for managing large amounts of information.

What are I/O Operations?

I/O stands for Input and Output operations. These operations are used to read data from users or files and write data to the screen or files.

Types of I/O Operations

  • Input Operation – Accepting data from user or file
  • Output Operation – Displaying or storing data
  • File Handling – Reading and writing files

Input and Output Functions

Example
name = input("Enter Name: ")

print("Welcome", name)
Input : John
Output : Welcome John

File Handling in Python

Python supports file handling operations using built-in functions. Files can be opened in different modes such as read, write, append, and binary mode.

Mode Description
r Read Mode
w Write Mode
a Append Mode
rb Read Binary Mode
wb Write Binary Mode

Opening a File

Syntax
file = open("filename.txt", "mode")
Example
file = open("sample.txt", "w")

file.write("Python File Handling")

file.close()
Output : File Created Successfully

Using with Statement

The with statement automatically closes the file after operation completion. It improves file safety and reduces errors.

Example
with open("data.txt", "w") as file:

    file.write("Hello Students")

Reading Data from File

Example
with open("data.txt", "r") as file:

    content = file.read()

    print(content)
Output : Hello Students

What are Collection Packages?

Python Collection Packages are specialized container data structures available in the collections module.

These collections provide additional functionalities compared to normal lists, tuples, and dictionaries.

Advantages of Collection Packages

  • Improves data organization
  • Provides efficient data storage
  • Reduces coding complexity
  • Supports faster operations
  • Useful for real-time applications

Important Collection Classes

Collection Description
Counter Counts frequency of elements
deque Double-ended queue
defaultdict Dictionary with default values
namedtuple Tuple with named fields
OrderedDict Maintains insertion order

Counter Collection

Counter is used to count frequency of elements in a list or string.

Example
from collections import Counter

text = "python"

result = Counter(text)

print(result)
Output : Counter({'p':1, 'y':1, 't':1, 'h':1, 'o':1, 'n':1})

deque Collection

deque allows insertion and deletion from both ends efficiently.

Example
from collections import deque

data = deque([10,20,30])

data.appendleft(5)

data.append(40)

print(data)
Output : deque([5, 10, 20, 30, 40])

defaultdict Collection

defaultdict automatically assigns default values for missing keys.

Example
from collections import defaultdict

data = defaultdict(int)

data["a"] += 1

print(data["a"])
Output : 1

namedtuple Collection

namedtuple gives names to tuple fields for better readability.

Example
from collections import namedtuple

Student = namedtuple("Student", ["name", "age"])

s1 = Student("John", 20)

print(s1.name)
Output : John

Program 7 – Name Sorting and File Storage

Program
def sort_and_save_names(names, filename):

    sorted_names = sorted(names)

    with open(filename, 'w') as file:

        for name in sorted_names:

            file.write(name + '\n')

    return sorted_names


def main():

    names = []

    filename = 'sorted_names.txt'

    while True:

        name = input()

        if name.lower() == 'q':
            break

        names.append(name)

    sorted_names = sort_and_save_names(names, filename)

    for name in sorted_names:
        print(name)

if __name__ == "__main__":

    main()
Logic
  • User enters multiple names.
  • Input stops when user enters q.
  • Names are sorted alphabetically.
  • Sorted names are stored into a file.
  • Sorted output is displayed.
Input : John Alice David q

Output : Alice David John

ChainMap Collection

ChainMap is a collection class available in the collections module. It is used to combine multiple dictionaries into a single view without merging them permanently.

ChainMap helps programmers search values across multiple dictionaries efficiently. It is useful in applications involving department records, configuration settings, and data lookup systems.

Program
from collections import ChainMap

n1 = int(input())

dept_a = {}

for _ in range(n1):

    name, phone = input().split()

    dept_a[name] = phone


n2 = int(input())

dept_b = {}

for _ in range(n2):

    name, phone = input().split()

    dept_b[name] = phone


q = int(input())

queries = [input().strip() for _ in range(q)]


merged = ChainMap(dept_a, dept_b)


for name in queries:

    print(merged.get(name, "Not found"))
Logic
  • The program creates two dictionaries for two departments.
  • User enters employee name and phone number.
  • ChainMap combines both dictionaries.
  • The query names are searched in merged dictionaries.
  • If name exists, phone number is displayed.
  • If name is missing, "Not found" is printed.
Explanation
  • ChainMap() combines multiple dictionaries into one view.
  • input().split() separates name and phone number.
  • merged.get() searches safely without generating errors.
  • "Not found" is displayed for unavailable entries.
Input :

2

John 9123456780
2
David 9988776655
Maria 9871234567
3
Alice
Maria
Steve

Output :

9876543210
